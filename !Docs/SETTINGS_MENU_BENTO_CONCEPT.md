# 🧭 Концепция единого меню в стиле «Google Apps / Bento Grid» для CoinLover (Dark Theme)

## 1. Проблема текущего решения
Сейчас меню разделено на два экрана через слайд-переход `НАЗАД / НАСТРОЙКИ >`:
1. **Экран 1**: Лента, Календарь, Аналитика, Настройки (стрелка перехода), блок Ask AI (Type / Voice).
2. **Экран 2**: Выбор темы (3 кнопки), Пересчитать балансы, Безопасность (Passkey), Приложение (QR/APK).

---

## 2. Предлагаемое решение: Google Waffle / Bento Grid (Сетка 3 колонки)

```
┌────────────────────────────────────────────────────────────┐
│   МЕНЮ                                              ✕      │
├────────────────────────────────────────────────────────────┤
│  [ ☀️ Светлая ]      [ ✨ Мята ]      [ 🌙 Тёмная  ● ]     │  <-- Переключатель тем
├────────────────────────────────────────────────────────────┤
│                                                            │
│     ┌──────────────┐   ┌──────────────┐   ┌──────────────┐ │
│     │      📋      │   │      📅      │   │      📊      │ │
│     │    Лента     │   │  Календарь   │   │  Аналитика   │ │
│     └──────────────┘   └──────────────┘   └──────────────┘ │
│                                                            │
│     ┌──────────────┐   ┌──────────────┐   ┌──────────────┐ │
│     │      🔄      │   │      🔑      │   │      📱      │ │
│     │ Пересчитать  │   │  Биометрия   │   │  Приложение  │ │
│     │   балансы    │   │  (Passkey)   │   │   (Скачать)  │ │
│     └──────────────┘   └──────────────┘   └──────────────┘ │
│                                                            │
├────────────────────────────────────────────────────────────┤
│   ASK AI ASSISTANT                                         │
│   ┌────────────────────────────┬─────────────────────────┐ │
│   │    ⌨️  Текст (Type)        │   🎙️  Голос (Voice)      │ │
│   └────────────────────────────┴─────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```

## 3. Детали и параметры
- Стиль: **Linear Dark** (`#050505`, `rounded-[28px]`, `border-white/10`, акцент `#6d5dfc`).
- Ширина: `w-[320px]`, открывается над FAB-монетой.
- Доступность: все действия выполняются в **1 тап** без вложенных экранов и ожидания слайд-анимаций.
