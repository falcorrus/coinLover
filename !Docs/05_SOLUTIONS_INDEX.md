# 📚 CoinLover: Решения и Устранение проблем

> Это краткий индекс основных исправлений. См. `!Docs/!SOLUTIONS.md` для полных деталей.

## 🔧 Платформенные исправления
- **Персистентность iOS PWA:** Используйте роутинг через пути (`/s/[ID]`) и Cookie на 1 год для связи Safari и PWA-контейнера.
- **Android Notch ("Челка"):** Используйте `env(safe-area-inset-top)` в обертке (wrapper), а не в фоне, чтобы сохранить консистентность цветов под челкой.
- **Кнопка "Назад" на Android:** Слушайте событие `backButton` через плагин Capacitor App, чтобы закрывать модалки вместо выхода из приложения.

## 🐛 Исправления багов
- **Смещение DND:** Перенесите `DragOverlay` в корень и удалите `transition: all` у перетаскиваемых элементов для устранения задержки курсора.
- **Отрицательные балансы:** Используйте робастный `parseNum` для обработки типографских минусов (`–`, `—`) из Google Таблиц.
- **Мерцание Сторис:** Всегда держите список сторис в DOM; рендерите плеер как параллельный фиксированный оверлей.
- **Логика Numpad:** Разделите поля Source/Target с функцией "Unlink" для ручного ввода курса обмена.
- **Ложный клик после удержания FAB:** Размонтирование кнопки FAB при открытии AI-листа прерывает генерацию браузерного клика после отпускания пальца.
- **Китайские иероглифы в голосовом вводе:** Добавьте службу распознавания речи в секцию `<queries>` манифеста Android, чтобы задействовать нативный плагин вместо багнутого WebView Speech API.
- **Зависание/мгновенное закрытие микрофона в APK:** Отделите запуск нативного плагина распознавания от немедленного завершения (вызванного мгновенным разрешением промиса при `partialResults: true`) через асинхронную подписку на шину `"listeningState"`.
- **Сбой балансов при удалении/обновлении переводов:** Добавлен фолбек на сопоставление кошельков по имени (нечувствительно к регистру) в дополнение к ID. Это предотвращает рассинхронизацию балансов при удалении/изменении транзакций, у которых `accountId` / `targetId` содержат имена из-за опечаток регистра в GAS или ручных правок.
- **Затирание листа Configs при редактировании транзакций:** В `useTransactions.ts` расчет обновленных балансов вынесен из асинхронного колбэка React `setAccounts` в синхронный код с защитным фильтром `accountsToSync`. На бэкенде в `api/sheets.ts` добавлен запрет на затирание: перед записью сервер вычитывает существующие кошельки/категории/доходы с листа и объединяет их.
- **Сортировка истории операций внутри дня:** Добавлена функция `sortTransactionsDesc` (ISO-время + обратный порядок по ID), гарантирующая отображение последних операций дня сверху в «Ленте (истории)» и «Календаре операций».
- **Ошибка 403 (master_sheet_restricted) для владельца:** Запрет доступа к `MASTER_SS_ID` сужен исключительно до опасного действия `initTable`, операции чтения финансовых данных владельца разблокированы.
